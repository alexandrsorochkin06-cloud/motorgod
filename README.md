# MotorGod ⚙️

Инженерная web-платформа для расчётов и анализа электродвигателей.

## Статус

**v0.1 — foundation**

Сейчас реализованы:

- React + TypeScript + Vite
- адаптивный мобильный интерфейс
- базовый анализ частоты и оборотов
- предварительная оценка числа полюсов
- GitHub Actions для сборки и GitHub Pages для публикации

## Архитектурный принцип

Критические инженерные расчёты будут выполняться детерминированным расчётным движком. AI в будущем будет использоваться как интерфейс и помощник, но не как источник непроверенных чисел.

4. Таблица пазов и катушек.
5. SVG-генератор схем.
6. Тестовые эталонные расчёты.
7. База знаний по типам двигателей.
